## About

I build things that connect software to the real world: microcontrollers that read sensors, models that classify what a camera sees, and game systems that depend on solid physics. My work spans Python, C#, Java, and C++, with hands-on hackathon experience in IoT and AI, and a background in robotics, competitive debate, and informatics competitions.

I'm currently working toward a Computer Science degree and building a portfolio of projects that go from idea to deployment.
